# DeepSteam：连接模型、工作区与卸载

在「连接模型」点击「登录 DeepSeek」，程序打开官方授权页面。完成授权后会自动验证并启用连接，页面显示授权、验证、保存的进度，无需再依次点击验证和启动。验证会使用少量账号额度；只有真实验证与保存成功才显示已连接。取消、登录失效或验证失败时会保留之前可用的设置。API Key 入口使用同样的「连接并启用」流程。

连接会设为 DeepTutor 的默认语言模型。任务模型和未单独指定的读图模型跟随默认连接。已有连接可以选择其他模型并点击一次使用，无需重复输入密钥；已启用的旧版桌面连接升级时同步默认选择，不要求重新登录。

DeepTutor 原来的「设置 → 模型」保留，可以另选服务商、切换模型，或者为某个会话单独指定模型。后续明确选择的独立模型仍按你的选择使用。界面的服务商和模型名表示实际选择；程序内部的网关地址和路由编号不需要手填。

## 上下文容量随模型切换

聊天、工作区智能体和互动课堂分别读取当前实际模型的上下文容量；本地千问的 16,384 限制仅用于本地千问，不再封顶其他服务商。旧版桌面 DeepSeek 路由会补齐模型容量元数据，界面显示实际模型名称，不使用内部路由编号推测容量。

上下文总容量、预计输入占用和本次输出预留是不同值。较大的最大输出容量不等于每次都预留全部容量。未知模型使用明确的回退值，并保留设置中的手动容量入口。不会为修正显示删除已有聊天。

## 嵌入、语音和其他接口

语言模型、嵌入模型、语音和外部视频生成属于不同能力。当前 DeepSeek 桌面连接提供聊天及经验证支持的图片输入，没有 `/embeddings` 接口。不能把聊天网关填入嵌入配置；程序会说明原因并阻止这个错误调用。

已有的嵌入、语音及其他 API 设置会保留。它们不会因为切换聊天模型而被覆盖。没有配置的独立能力会明确显示未配置，不会显示为已接通。本次没有新增收费服务或下载嵌入模型。

## 选择工作区文件夹

在桌面程序的工作区入口点击「打开文件夹」，选择电脑上实际存在的文件夹后立即进入这个工作区，不需要先填写新建表单。文件夹名称会作为默认工作区名称；已经登记的同一文件夹会直接复用。DeepTutor 与 Harness 登记同一个规范路径，界面显示完整文件夹位置；选择操作不会搬走原始文件。

新会话使用当前工作区的实际目录，已有会话可以恢复。切换目录仍从工作区入口选择；「打开所在文件夹」会在 Windows 文件资源管理器中打开当前已登记的位置。

左侧工作区标题支持右键和三点菜单，可以新建聊天、重命名、打开所在文件夹或删除工作区。删除前有确认，删除的是工作区列表里的登记状态，原文件、聊天和智能体会话保留；可以从「已删除工作区」恢复。系统和通用工作区不提供删除操作。工作区仍有任务执行或等待批准时，先停止相关任务再操作。

工作区助手可以读取文件和图片、搜索内容、写入或修改文件，并通过 Harness 执行命令。会话记录与工作目录关联，重启后可继续已有会话。执行需要确认的操作时，界面显示具体操作或命令；取消后不继续提交迟到的操作结果。

文件工具检查所选工作目录及受保护的凭据目录。终端按照当前 Windows 用户的权限执行经确认的命令；它不是禁止读取工作区之外文件的系统沙箱。

## 从桌面打开与退出

安装后使用桌面上的「DeepSteam」快捷方式打开。学习、模型设置和互动课堂都通过窗口内入口进入；程序会管理内部服务，用户无需打开网页书签、填写本机地址或配置端口。搭档在自己的电脑上安装和启动即可。

完成学习后关闭桌面窗口，程序会停止本次启动的服务。升级首次打开会迁移同一安装的界面数据，旧数据保留；不要在迁移过程中强行关闭程序。模型连接、学习记录与工作区文件继续保存在所选的数据和工作目录中。

需要手工配置其他服务商时，只填写该服务商提供的 API 地址。内置服务由 DeepSteam 管理。内部通信仍封装使用本机回环，产品不对局域网或公网开放。

## 备份与继续学习

先关闭 DeepSteam，再备份安装目录、所选的数据目录，以及你自己选择的工作区文件夹。本机采用 D 盘运行和独立的数据目录；分享安装包不包含你的账号、资料和学习记录。不要把分享包当作个人数据备份。

下次打开后，从左侧工作区选择原会话继续学习。换到另一台电脑时，先安装程序，再恢复需要的资料和记录，并重新完成模型账号登录；不要把自己的登录凭据交给搭档。

## 一键卸载

新版安装会提供「卸载 DeepSteam」入口，也可以打开安装目录中的 `Uninstall-DeepSteam.exe`。

默认卸载程序并保留学习记录、配置和原始工作文件。卸载窗口中的数据清理选项是独立选择；它只清理能够验证属于本安装的软件数据，并保护已登记的工作区。未确认属于程序的文件、被用户修改的文件以及被占用而无法安全处理的文件会保留或说明失败，避免显示虚假的卸载完成。

代码测试、受控接口测试与真实文件及进程测试会分别记录。课堂内容生成和新的付费模型推理按用户要求暂不测试；不能用本地测试结果声称所有云端能力已实际验收。

本次扩展集中在工作区工具、默认模型统一配置和卸载。官方 Harness 的浏览器操作、远程扩展等可选插件不应据此视为全部配置完成。
